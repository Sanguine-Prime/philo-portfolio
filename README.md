# Philopatir George Ibrahim — Portfolio

A responsive single-page React portfolio starter.

## Requirements
- Node.js (LTS recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Before publishing
- Add your preferred email in `src/App.jsx` (replace `href="mailto:"`).
- Review project descriptions and ensure they reflect your exact contributions.
- Add project screenshots when available.
- Update the page title and metadata in `index.html` if desired.

This is a static frontend; it does not require a backend.
